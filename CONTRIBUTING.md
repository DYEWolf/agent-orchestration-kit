# Contributing

Thank you for helping improve `agent-orchestration-kit`.

1. Open an Issue before substantial work so scope and acceptance criteria are clear.
2. Use Node.js 22 or newer and install dependencies with `npm ci`.
3. Run `npm run check` before submitting a pull request.
4. Keep external mutations explicit and preserve the ChangePlan-before-write invariant.
5. Do not add fetched-at-install-time templates, credentials, or unreviewed upstream skill content.

Contributions are accepted under the repository's MIT License. Third-party
content must include complete provenance and compatible licensing.
